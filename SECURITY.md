# Security

Report a vulnerability in the Warp MCP connector (mcp.wearewarp.com) to r.ankarath@wearewarp.com. Include the URL or tool involved, steps to reproduce, and any request IDs. We reply within 2 business days.

Please do not test against other users' accounts or make real bookings.

Incident handling: [docs/security/incident-response.md](docs/security/incident-response.md).
